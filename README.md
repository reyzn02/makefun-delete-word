Deletes the word "queue" from the dictionary — a five-letter word that is really just the letter Q dragging four silent letters behind it. Erase it and the most wasteful spelling in English goes with it: nobody has ever sounded out the "ueue", and nobody would miss it.

## Run it

```sh
python3 main.py
```

The program writes the single word `queue` to `/output/entry.txt`.
